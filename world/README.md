# Мир игры: тренировочный остров (этап 1)

Остров строится при запуске из данных, ничего не расставлено вручную в сцене.

| Что | Где |
|---|---|
| Референсы (утверждены Максимом) | `reference/training_island.png` — главный, `reference/world_map.png` — весь мир на будущее |
| Конфиг острова | `world/training_island.json` |
| Маска берега и расстояние до берега | `world/training_island_land.png`, `world/training_island_coast.bin` (+ `.png` для просмотра) |
| Сверка конфига с референсом | `world/training_island_overlay.png` |
| Скрипт подготовки масок | `tools/extract_island_masks.py` |
| Ядро (рельеф, коллизия, проходимость, зоны, спауны) | `island_world.gd` (`IslandWorld`) |
| Вода, берег | `island_water.gd` (`IslandWater`) |
| Постройки и точки интереса | `island_pois.gd` (`IslandPois`) |
| Модели построек, декора и природы из файлов (Meshy) | `assets/props/`, `prop_asset.gd` (`PropAsset`), `prop.gdshader`, делает `tools/prepare_props.py`; нет файла — процедурные `poi_models.gd` |
| Растительность, качество, постобработка | `island_vegetation.gd`, `quality.gd`, `postfx.gd` |
| Рисованные текстуры земли и построек | `world_textures.gd`, `assets/textures/` (делает `tools/gen_textures.py`) |

## Координаты
Метры. `x` — восток, `z` — юг (север сверху, как на картинке). Город новичков — в `(0, 0)` на высоте 0,
уровень моря −2.5 м. Пересчёт из пикселей референса (1792×1008):
`x = (px − 890) × 0.2`, `z = (py − 520) × 0.2` (поля `reference.origin_px` и `meters_per_px` в конфиге).

## Что в конфиге
- `heights` — уровни: море, дно, город, высота холмов, глубина русла, шаг сетки.
- `river.branches` — ломаные русла (концы уходят в море), `width`, `water_level`. `ponds` — пруды.
- `roads.paths` — дороги-ломаные, `width`. Где дорога пересекает реку, мост ставится сам.
- `pois` — точки интереса: `id`, `type`, `name`, `center`, `radius`/`size`/`rotation`/`length`,
  `flatten` (радиус ровной площадки под постройки), `hill` (холм, например с пещерой).
- `safe_zones` — безопасные зоны (звери туда не заходят): город, деревни, порт, а ещё `hunter_camp` (Западный
  лагерь, там охотница) и `merc_post` (пост главы наёмников у входа в пещеру, вне логова анатем). Жители-NPC
  стоят около центров POI или этих зон (`NpcData` поле `spot`, расстановка — `Npcs.place_all`).
- `spawn_points` — старт игрока по расам: `human`, `light_elf`, `dark_elf` (+ `default`).
  Здесь же игрок возрождается после смерти.
- `mob_zones` — зоны зверей: центр, радиус, уровни `[мин, макс]`, список `[вид, количество]` (или
  `[вид, количество, мин, макс]`). Характеристики и опыт — из статов по уровню (`MobStats`).
- `transitions` — переходы (порт → материк, пока сообщение-заглушка).

## Зоны уровней (1–30), настраиваются в `mob_zones`

(модели из примитивов) больше нет. Характеристики зверя — из 7 статов по уровню (`MobStats`), бой — `Combat`
(подробно — CLAUDE.md, «Бой, статы зверей, опыт, боссы»). С 12 ур. дикие звери — модели 2-й стадии, с 22 — 3-й.

## Как добавить объект или деревню
1. Добавьте запись в `pois` конфига (свой `id`, `type`, `center`, при необходимости `flatten`).
2. Если тип новый — добавьте функцию постройки этого типа в `island_pois.gd` (по образцу существующих).
3. Безопасная зона — запись в `safe_zones`, точка старта — в `spawn_points`, дорога — в `roads.paths`.
4. Если меняли реку или пруды — пересоберите маски: `python3 tools/extract_island_masks.py`
   (нужен Pillow), он же обновит картинку сверки `world/training_island_overlay.png`.

## Новый остров/материк по той же схеме
Положите референс, сделайте новый конфиг (скопируйте структуру), запустите скрипт масок с путями
в конфиге и укажите путь к конфигу в `IslandWorld.CONFIG_PATH` (позже — выбор зоны при загрузке).

## Проходимость (вместо навмеша)
Сетка с шагом 1 м: суша проходима, вода (море, река, пруд) и крутые склоны (перепад больше 0.9 м
на клетку) — нет, мосты — да. Игрок, звери и питомцы после каждого шага проверяют клетку
(`IslandWorld.constrain`), поэтому не заходят в воду и не проваливаются сквозь землю.

## Запуск и проверка
- Игра: открыть проект в Godot 4.3 и запустить (F5). Новый персонаж стартует в деревне своей расы.
- Автотест острова: `tests/test_island.gd` (запуск — см. `CLAUDE.md`, раздел «Проверка и сборка»).
- Вид сверху для сверки с референсом: скриншот `00_island_top.png` в ветке `ci-screenshots`
  (делает задача CI `visual`).
