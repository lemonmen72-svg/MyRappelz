# Система анимаций 1.0 — аудит (фаза A)

Дата: 04.11.2026 · Godot 4.3 (GDScript) · Android: Mobile (Vulkan) с запасным Compatibility, ПК/CI — Compatibility.
Основа: ТЗ `DARK_PACT_ANIMATION_SYSTEM_MASTER.md`. Матрица покрытия — `ANIMATION_COVERAGE.csv` (пишет тест
`tests/test_anim_system.gd`), инвентарь клипов — `ANIMATION_INVENTORY.csv` (`python3 -I tools/anim_inventory.py`),
риски — `RISK_REGISTER.md`, устройство — `PROPOSED_ARCHITECTURE.md`.

## 1. Граф сцены героя
- `Player` (`CharacterBody3D`, `player.gd`) двигает тело кодом (скорость, `floor_snap`), **root motion нет**: все клипы
  на месте (`CharacterModel._pin_root`, в конвейере — `plant_inplace`, `make_loco`).
- `CharacterModel` (`Node3D`, `character_model.gd`) — модель героя: экземпляр GLB `assets/characters/<id>.glb` →
  `Skeleton3D` (риг Meshy, кости по ролям из `<id>.json`) + один `AnimationPlayer`. **AnimationTree нет**: клипы
  играет код (`_asset_process` — покой, шаг, бег; `_asset_act`, `_mq_play` — действия), переходы — `play(…, blend)`.
- `TwoHandIK` (`SkeletonModifier3D`) — вторая рука на двуручном, арбалете, луке; `BoneAttachment3D` — оружие в кистях
  (`Handheld`: модели из файлов, иначе процедурные меши). `ModelLod` — контур дальних моделей.
- Модель из примитивов (нет пакета ресурсов) — процедурные кости и жесты (`play_attack`, `play_cast` … без клипов).

## 2. Расы, пол, профессии, оружие
- 3 расы × 2 пола; 9 профессий + Бродяга. Моделей героев 24 (`hero_<профессия>_<m|f>`, `hero_<раса>_<m|f>_starter`)
  + прежняя `dark_elf_wanderer` + запасные люди в APK.
- **Пол** — одинаковые имена клипов у всех героев; женская пластика запечена в клипы при подготовке
  (`tools/prepare_hero.py` `feminize`, `retarget_mannequin.py` стили `mq_*`). Выбор клипа от пола не зависит
  (ортогонально профессии и оружию, как требует ТЗ 3.4).
- Хваты (`CharacterModel.mq_grip`): sword, sword_shield, sword_2h, dual_swords, dagger, daggers, axe, axe_2h,
  dual_axes, mace, mace_2h, spear, staff, bow, crossbow; без оружия героя не бывает.
- Умения: 156 умений профессий + 27 Наёмника, вид анимации — `HeroSkillFx.anim` / `Player.SKILL_ANIM`
  ("cast", "bash", "spin", "buff", "dash", "attack"), способ `use` ("melee", "ranged", "magic", "self", "pet").

## 3. Клипы
У каждого героя 81 клип: 20 Quaternius UAL (Idle, Walking, Running, Sword_* , Crossbow_*, Cast, Hit, Death, Dodge,
Pickup, Wave) и 61 клип манекенов Meshy `Mq_*` (атаки по хватам, удары умений, касты, петли `_Hold`, повороты, шаг и
бег манекенов). У жителей — 20 клипов UAL. Длина, петля, момент удара (`hit`), своя скорость, поворот — в `<id>.json`.
Полный список с тем, какие константы кода их выбирают, — `ANIMATION_INVENTORY.csv` (2204 строки, 37 моделей).
- Не выбирались кодом: **`Sword_Idle`** (боевая стойка) — теперь боевой покой (см. ниже). `Mq_Reload`, `Mq_Rise`
  выбираются по имени (перезарядка арбалета, возрождение).
- Звери и питомцы — отдельная семья ригов (`CreatureAsset`, процедурные клипы Idle/Walk/Run/Attack/Hit/Death/Cast,
  стили cat / turtle / bird / fish / biped / centaur) — гуманоидный перенос к ним не применяется (фаза F).

## 4. События (договор синхронизации, ТЗ §6)
| Что | Кто решает | Когда | Анимация |
|---|---|---|---|
| Урон обычной атаки | `Player.try_attack` | сразу при атаке; второй удар пары — таймер `HIT_GAP` | только показ |
| Снаряд (лук, арбалет, посох) | `Player._shoot` → `Projectile` | при атаке, из точки перед грудью (+1.25 м, 0.6 м вперёд) | только показ |
| Урон / лечение / статус умения | `HeroSkillFx` | конец каста (`Player._finish_cast`) или сразу (мгновенные) | `play_skill`, выпуск — с момента удара клипа |
| MP, перезарядка | `Player._finish_cast` / `HeroSkillFx` | по игровому времени | не зависит |
| Каст | `Player._tick_cast` (время, скорость каста) | ходьба, смерть цели, смена оружия — прерывают | петля `play_cast_loop` / `stop_cast_loop` |
| Урон по герою | `Player.take_damage` | от зверя | `play_hit` (реакция только стоя и без каста) |

Итог: **геймплей от клипов не зависит** — ни урон, ни MP, ни перезарядка не ждут конца или метки клипа; смена клипа не
сбрасывает перезарядку (`attack_cd`, `cooldowns` в `Player`). Проверено тестом: урон 10 обычных атак одинаков при
включённой и выключенной системе (`tests/test_anim_system.gd`). Сети нет (игра офлайн). Момент удара клипа
(`_act_hit`) — только визуальный: после него движение прерывает действие.

## 5. Найденные дефекты и что сделано
1. Удар умения (bash / attack ближнего боя) с **луком или арбалетом** играл взмах мечом `mq_charged_slash` (запасной
   вариант для любого хвата не из таблицы) — теперь у лука натяжение (`MQ_BOW_SKILLS`), у арбалета — прежний выстрел.
2. **Круговой удар посохом** играл кручение с топором `mq_axe_spin` — теперь удары посохом (`MQ_STRIKES.staff`).
3. **Боевой стойки не было**: клип `Sword_Idle` есть у всех героев, но не играл — теперь боевой покой (6 с после
   атаки, умения или удара по герою, одноручное оружие ближнего боя; поворот на месте его снимает — поворот кончается
   позой обычного покоя без перехода). `Sword_Idle` зациклен при подготовке клипов.
4. **Нет диагностики** выбора: что сыграло и чего не хватило — не видно. Теперь `AnimResolver` считает решения по
   уровням, пропуски и последние 64 решения; строка в отчёте тест-бота и в `cardinal.json` (`anim`).
5. Выбор клипа был разбросан по `play_skill` / `_mq_attack` / `_asset_act` без общей цепочки — теперь цепочка уровней
   `AnimResolver` (прежний код оставлен за флагом).

## 6. Производительность
Резолвер работает только при действии (атака, умение, урон), не каждый кадр; таблицы — короткие массивы констант.
Каждый кадр добавлена одна проверка `in_combat_stance()` в ветке покоя. Замеров на телефоне ещё нет — режим бота
«Производительность» после сборки покажет к/с и кадр (ТЗ §8 п. 7: числа не придумываем).

## 7. Неизвестное / не сделано
- На Samsung Galaxy S24 Ultra и Tab S10 FE+ система ещё не проверялась (проверка — после сборки, шаги в
  `PROPOSED_ARCHITECTURE.md` «Проверка на телефоне»).
- Смерть героя: клип `Mq_Death` есть, но игрок возрождается сразу — состояния смерти в геймплее нет (не выдумываем).
- Оглушения / сна / страха у героя нет — клипов не нужно.
- Жители, питомцы, звери (фазы E, F) — пока прежние контроллеры (`Npc`, `CreatureAsset`).
