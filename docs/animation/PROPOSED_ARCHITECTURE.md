# Система анимаций 1.0 — устройство и план

## Слой выбора клипа — `AnimResolver` (`anim_resolver.gd`)
Один вход для решений «какой клип сыграть» у героя из файла. Контекст: действие (обычная атака, вид умения
"cast" / "bash" / "spin" / "buff" / "dash" / "attack"), id умения, способ `use`, хват `CharacterModel.mq_grip()`,
ближний бой или нет. Данные (какие клипы) — константы `CharacterModel` (`MQ_ATTACKS`, `MQ_STRIKES`, `MQ_SPINS`,
`MQ_CASTS`, `MQ_BUFFS`, `MQ_SKILL_BY_ID`, `ASSET_ACTIONS`, `ASSET_IDLE_COMBAT`); резолвер задаёт порядок уровней.

Цепочка (ТЗ §4, от точного к общему):
1. `skill` — своё движение умения (`MQ_SKILL_BY_ID`: «Вызов» — `mq_taunt`, удары по земле …);
2. `grip` — вид действия + хват (атаки, удары, круговые по хвату; лук — натяжение);
3. `shared` — общий клип вида (касты, усиления, `mq_charged_slash`, `mq_axe_spin`, рывки клинками); у лука и
   арбалета общего взмаха мечом нет;
4. `legacy` — прежний жест модели (`ASSET_ACTIONS`: slash/combo/spin/leap/cast/buff/shoot), у модели из примитивов —
   процедурные удары;
5. `idle` — ничего нет: действие не играет, герой в покое или шаге (не зависает, не падает).

Пол в цепочке не участвует: у всех героев одинаковые имена клипов, мужская и женская пластика запечена в сами клипы.
Если появится клип только для одного пола — уровень «variant» вставляется перед `grip` (ключ `<клип>_f` / `_m`).

**Флаги отката** (до перезапуска; админ-панель → «Тест-бот» → «Анимации»): `AnimResolver.enabled = false` — прежний
код выбора клипов (оставлен в `CharacterModel.play_skill`), `AnimResolver.combat_idle = false` — без боевой стойки.

**Состояния** (как сейчас в игре, без выдумок): покой / боевой покой / шаг-трусца-бег-быстрый бег (по скорости) /
поворот на месте / петля каста / действие (атака, умение, урон, подбор, уклонение, блок, эмоция, подъём). Приоритет:
петля каста > действие до конца или до момента удара (движение прерывает после `hit`) > шаг > покой. Смерть и контроль
у героя в геймплее не наступают.

## Диагностика и Кардинал (фаза G)
`AnimResolver.note` на каждое решение: счётчики действие → уровень, пропуски `действие/хват` (уровни legacy и idle),
след последних 64 решений (время, действие, хват, умение, уровень, клип). Сброс — при старте тест-бота.
- Отчёт тест-бота: строка «Анимации (AnimResolver): запросов N: skill …, grip …, shared …, legacy …, idle …; без
  своего клипа: …».
- Кардинал: `cardinal.json` → `anim` (`AnimResolver.summary()`). Только чтение: Кардинал ничего не меняет.
- Матрица покрытия: `AnimResolver.coverage(модель, профессия, клипы)` по `<id>.json` (без загрузки GLB) — все герои ×
  15 хватов × 9 действий; статусы `verified` (проиграно на настоящей модели тестом), `implemented_unverified`,
  `missing`, `not_applicable` (профессия оружием не владеет; стрелковое умение без лука/арбалета).

## Проверки
`tests/test_anim_system.gd`: цепочки (лук и арбалет без взмаха мечом, посох, своё умение первым, нет клипов — legacy),
матрица всех героев (нет `missing`), срез Мечник + Мечница с мечом: атака → удар умения → щит → круговой → рывок →
усиление → на себя → петля каста → выпуск → урон → боевой покой → через 6 с обычный; меч в руке один; откат флагом;
модель без клипов не падает; 12 смен оружия подряд; урон 10 атак одинаков с системой и без.
Старые тесты (`test_hero_models`, `test_character_model`, `test_two_hand`, бой, умения, бот) — без изменений поведения,
кроме боевого покоя (две проверки «после удара — покой» принимают стойку).

## Проверка на телефоне (S24 Ultra, Tab S10 FE+)
1. Мечник с мечом: несколько ударов по зверю — после боя 6 с стойка с клинком, потом обычный покой; поворот на месте
   — без рывка позы.
2. Воин с луком: умения лука — натяжение, не взмах мечом. Наёмник с арбалетом: умения — выстрел.
3. Шаман / Волшебник с посохом: «Обвал», касты — петля и выпуск; круговой удар посохом — удар посохом.
4. Админ-панель → «Тест-бот» → «Анимации»: выключить систему — всё как в 0.28; включить обратно.
5. Отчёт бота «По разделам» → строка «Анимации …»; режим «Производительность» — к/с не хуже 0.28.
