# Система анимаций 1.0 — риски

| # | Риск | Вероятность / влияние | Мера | Статус |
|---|---|---|---|---|
| 1 | Резолвер выбирает не тот клип, чем прежний код (регрессия вида) | средняя / низкое | цепочка повторяет прежние таблицы; отличия — только 3 исправления из аудита; флаг отката `AnimResolver.enabled` (админ-панель → «Тест-бот» → «Система анимаций») | закрыт тестами `test_anim_system`, `test_hero_models`, `test_character_model`, `test_two_hand` |
| 2 | Боевая стойка дёргает позу на стыке (поворот, двуручное, IK) | средняя / низкое | только одноручное ближнего боя, поворот снимает стойку, у двуручного — хват наперевес; выключатель «Боевая стойка» | проверить на телефоне глазами |
| 3 | Геймплей начинает зависеть от клипа | низкая / высокое | урон, MP, перезарядка, каст — в `Player` / `HeroSkillFx` по игровому времени; тест: урон одинаков с системой и без | закрыт тестом |
| 4 | Нечёткий поиск `_clip(key)` (подстрока) берёт чужой клип в прежних жестах | низкая / низкое | новые цепочки — только точные имена (`_mq_clip`); прежние жесты оставлены как есть | известное ограничение |
| 5 | Нагрузка на телефон | низкая / среднее | резолвер — только при действии, кадр — одна проверка; учёт — массивы до 64 | измерить ботом «Производительность» |
| 6 | Диагностика копится без конца | низкая / низкое | счётчики по ключам, след — кольцо 64, сброс при старте бота | закрыт |
| 7 | Новая модель героя без каких-то клипов | средняя / низкое | цепочка: свой → хват → общий → прежний жест → покой; пропуск — в диагностике и матрице (`missing`) | закрыт, матрица в тесте |
| 8 | Перенос на жителей / зверей ломает их | — | фазы E, F отдельно; звери — своя семья ригов, гуманоидный перенос не применяется | не начато |
| 9 | Выводы без проверки на устройстве | — | статусы матрицы: `verified` только для проверенного на настоящей модели тестом; остальное `implemented_unverified` | правило соблюдено |
