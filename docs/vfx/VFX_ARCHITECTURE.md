# Dark Pact — генератор эффектов: устройство

Цель (слова Максима): генератор — инструмент, которым по названиям и описаниям умений собираются эффекты, и они
встраиваются в игру. Эффекты красивые и красочные: у стихии палитра из нескольких цветов, у эффекта 3–6 слоёв.

## Части

| Файл | Класс | Что делает |
|---|---|---|
| `vfx/vfx_kit.gd` | `VfxKit` | Слои: текстуры кодом (пламя, дым, знак секты, руны, когти, росчерк, капля, снежинка, трещины, волна, осколок, вихрь), меши (осколок, шип, камень, тор), частицы `CPUParticles3D` (форма, разлёт, гравитация, притяжение к центру, вращение по кругу, разброс оттенка), вспышка к камере, след на земле, сфера, тор, столб, дуга удара, молния, луч, шипы из земли, постоянные частицы (каст), краткий огонь (не больше 3 сразу). |
| `vfx/vfx_archetypes.gd` | `VfxArchetypes` | 39 архетипов + вид снаряда (`dress_projectile`). Палитры стихий `PALETTES` (17: огонь, лёд, вода, земля, молния, свет, лечение, тьма, изумруд секты, яд, кровь, ветер, дух, разум, сталь, щит, зверь): ядро, основной, второй, искры, дым. Качество q: 0 (×0.4 частиц, без вторичных слоёв), 1 (×0.7), 2 (×1, + краткий огонь). |
| `vfx/vfx_rules.gd` | `VfxRules` | Правила: стихия — по корням слов названия (×3) и описания (×1), полю `c` (×2), виду питомца (×1); архетипы фаз — по виду применения (`use` / `target`), анимации, оружию, площади, статусам, особым механикам (`HANDLERS`). |
| `vfx/vfx_generate.gd` | `VfxGenerate` | Проходит все умения героя (Наёмник + 8 профессий), питомцев (по видам) и способности монстров (удар по площади, проклятия), строит таблицу и каталог. |
| `tools/vfx_generate.tscn` | — | Запуск: `godot --headless --path . res://tools/vfx_generate.tscn` → `vfx/skill_vfx.json`, `docs/vfx/VFX_PRESETS_CATALOG.md`. |
| `vfx/skill_vfx.json` | — | Таблица (генерируется): `hero` {id}, `pet` {"вид:id"}, `mob` {"вид:slam", "вид:curse:<вид>"} → фазы. |
| `vfx/skill_vfx_overrides.json` | — | Ручные правки поверх таблицы (поля фазы дополняются, `null` — убрать фазу). |
| `vfx/skill_vfx.gd` | `SkillVfx` | В игре: таблица + правки, `play` фазы, удобные `impact`, `area_at`, `release`, `buff`, `cast_start` / `cast_stop`, `proj_style`; лимиты; выключатель `enabled`. |
| `vfx/vfx_flip.gd` | `VfxFlip` | Раскадровки (0.46.1): листы Максима `vfx/flip/fx_<id>[_N].png` (4×4 кадра по 256 px, оттенки серого, импорт «Image») и `flipbooks.json`; фоновая загрузка, заранее — при входе в мир (`prewarm_world`), не больше 30 листов в видеопамяти, выключатель `enabled`. Слой — `VfxKit.flipbook` (виды: к камере, стоит на земле, лежит на земле, вдоль удара, между героем и целью), в архетипах — `VfxArchetypes._flip` (лист есть — свои слои той же формы не рисуются). |
| `tools/prepare_flipbook.py` | — | Нарезка листов ChatGPT: сетка, яркость, край кадра, опора, петли; `tools/flipbook_sources.txt` — какой файл каким эффектом стал. |
| `vfx/status_fx.gd` | `StatusFx` | Ослабления на герое и звере — петли из листов над головой (оглушение, сон, страх, морок, проклятие) и у тела (путы, оковы, яд, кровь, горение, ослабление): узел-ребёнок, появляется при первом ослаблении (`StatusEffects.add`), уходит сам. |

## Пресет фазы

`{"arch": архетип, "el": стихия, "scale": размер, "dur": с, "k": насыщенность, "seed": число}` (+ `tint` [r, g, b] —
заменить основной цвет). Фазы записи: `cast` (на герое во время каста, длится время каста, гаснет при прерывании),
`release` (выпуск силы у рук), `proj` (`{"el"}` — вид шара-снаряда), `impact` (по цели), `area` (по площади вокруг
цели; у «near» — вокруг героя), `buff` (усиление / лечение / проклятие на ком-то). Seed — по id умения: вид
повторяется от запуска к запуску.

## Точки встраивания (эффекты — только картинка, урон и тайминги не меняются)

| Событие | Где | Вызов |
|---|---|---|
| Начало / конец / прерывание каста | `Player._begin_cast`, `_end_cast` | `SkillVfx.cast_start` / `cast_stop` |
| Умение профессии сработало | `HeroSkillFx.activate` | `release`; снаряд — `Player._shoot(…, proj_style)`; на себя / питомца — `buff` |
| Попадание умения | `HeroSkillFx.apply` (раз на применение; без урона — тоже), `Projectile._hit` (снаряд со `style`) | `impact` (+ `area`) |
| Умения Наёмника | `Player._cast_hero` (рывок, на себя, сон, удар, болт) | `release`, `buff`, `impact`, снаряд — `proj_style` |
| Включено переключаемое | `Player.set_toggle` | `buff` |
| Умение питомца | `Pet._apply_skill`, `_skill_fx`, `_area_fx`, `_extra_hit`, `_apply_buff`, «Омут порчи» | `release`, `impact`, `area`, `buff` |
| Удар по площади зверя | `Mob._slam` | `play("mob", "<вид>:slam", "area")` |
| Проклятие капитана | `Mob.curse_now` | `buff("mob", "dg_captain:curse:<вид>")` |

Нет записи или фазы — место вызова показывает прежний эффект `Vfx` (откат). Админ-панель → «Тест-бот» →
«Эффекты» → «Новые эффекты умений: вкл./выкл.» (`SkillVfx.enabled`, до перезапуска).

## Нагрузка

- Только `CPUParticles3D`, материалы без освещения, текстуры 64–128 px рисуются один раз и кэшируются.
- Качество — настройка «Качество эффектов» (`Quality.effective("effects")`, с учётом авто-снижения при нагреве).
- Дальше `SkillVfx.LOW_DIST` 26 м от камеры — низкое качество, дальше `FAR` 55 м — не строится.
- Больше `MAX_ACTIVE` 36 эффектов сразу — низкое качество, больше 54 — новые не строятся.
- Краткий огонь — только «Высокое», не больше `VfxKit.MAX_LIGHTS` 3 сразу.
- Эффект удаляет себя сам (`Vfx._root`: dur + 1.6 с), постоянные частицы каста гаснут по времени или при прерывании.

## Тест

`tests/test_vfx_gen.gd`: таблица = правила; у каждого активного умения героя и питомца есть эффект; разнообразие
(архетипов в таблице ≥ 30, стихий ≥ 12); каждый архетип строится на трёх качествах, многослойный (≥ 3 слоя), на
низком частиц меньше; снаряд каждой стихии; в бою — каст, выпуск, снаряд света, попадание, лечение, площадь, умение
волка, проклятие и удар капитана; выключатель; лимит; всё удаляется само.
