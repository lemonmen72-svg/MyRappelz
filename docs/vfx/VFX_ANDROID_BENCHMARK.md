# Эффекты — замеры на Android

**Не проверено.** Замеры на телефоне делает тест-бот: режим «Производительность», сцена «Бой с умениями» (умения
Неофита по кругу — с новыми эффектами). Сравнить: админ-панель → «Тест-бот» → «Эффекты» выкл. и вкл., по одному
прогону; в отчёте — к/с, худшая секунда, время видеочипа, температура.

Оценка без телефона (headless, CI): эффект на «Высоком» — 30–60 частиц и 3–8 мешей; все 39 архетипов вместе —
968 частиц на «Высоком», 679 на «Среднем», 298 на «Низком» (`tests/test_vfx_gen.gd`, строка «частиц на качествах»).
