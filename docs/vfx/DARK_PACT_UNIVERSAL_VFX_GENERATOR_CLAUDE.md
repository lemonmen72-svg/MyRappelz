# DARK PACT — Universal VFX Generator
## Мастер-ТЗ для Claude Code · версия 1.0

**Проект:** Dark Pact / MyRappelz, Godot 4.3, Android, 3D anime fantasy MMO.  
**Репозиторий:** `lemonmen72-svg/MyRappelz`; работай в текущей ветке, не создавай новую без разрешения.  
**Задача:** разработать **универсальный редактор и генератор визуальных эффектов** для навыков, оружия, существ, окружения и подземелий. Он должен создавать редактируемые, воспроизводимые, переиспользуемые VFX-сцены, а не только набор красивых демонстраций.

> **ВАЖНО:** это проектное ТЗ, а не утверждение, что перечисленные узлы, файлы и API уже есть. Сначала изучи настоящий репозиторий, архитектуру эффектов, навыков, анимаций, импорта, Android-рендера и настройки качества. Не ломай существующее. Не запускай сборку APK, GitHub Actions APK, не меняй `android/release_version.txt` и не создавай release-теги без отдельного явного разрешения владельца.

## 1. Цель и критерии успеха

Создать инструмент внутри Godot (при необходимости — с опциональным Blender-пайплайном), позволяющий:

1. Выбрать **архетип** (огненный шар, взрыв, магический круг, призыв, удар клинком, призрак, туман, волна воды, удар по земле и т. п.).
2. Указать параметры: стихия, цвет, размер, длительность, скорость, интенсивность, форма, направление, привязка к кости/цели, качество и число частиц.
3. Получить **сохранённый ресурс-пресет и игровую VFX-сцену**, с предпросмотром, возможностью ручной правки и повторной генерации по seed.
4. Привязать эффект к существующему событию боевой системы: `cast_start`, `cast_release`, `projectile_spawn`, `projectile_hit`, `weapon_swing`, `weapon_hit`, `buff_start`, `buff_loop`, `buff_end`, `death`, `summon`, `environment` — это логические примеры; адаптировать к реальным событиям проекта.
5. Использовать эффекты на Android без постоянной работы нейросети и без обязательного облачного API.
6. Поддерживать пакетное создание десятков/сотен вариантов через конфигурации и пресеты.

**Не цель v1:** полноценная нейросетевая генерация произвольной 3D-симуляции по тексту на смартфоне. Текстовый ввод допускается только как необязательный офлайн-парсер параметров или отдельный подключаемый адаптер; базовая генерация должна работать детерминированно без ИИ.

## 4. Архитектура (предлагаемая, адаптировать по итогам аудита)

### 4.1. Редакторский генератор

- `EditorPlugin` с панелью **Dark Pact VFX Studio**.
- Выбор архетипа, стихии, палитры, длительности, масштаба, seed, бюджета частиц, LOD, attach point, timing.
- Кнопки `Generate`, `Preview`, `Stop`, `Regenerate`, `Save Preset`, `Save Scene`, `Validate`, `Batch Generate`.
- Предпросмотр на нейтральной тестовой площадке с манекеном, оружием, целью, переключателем фона, скоростью воспроизведения, отображением FPS и числа активных частиц.
- Не изменять оригинальные модели и сцены при генерации. Сохранять в отдельной директории, выбранной после аудита.

### 4.2. Данные

Использовать типизированный `Resource` (или существующую систему данных) с сериализуемыми параметрами. Пример схемы, **не готовый API**:

```text
VFXPreset
  id, display_name, category, element, seed
  palette: primary, secondary, accent, glow
  duration, looping, scale, intensity
  spawn_shape, emission_rate, particle_count, particle_lifetime
  velocity, gravity, drag, turbulence, size_curve, alpha_curve
  layers[]: mesh / particles / decal / shader / light / trail / flipbook / sound_hook
  timing: start, impact, fade
  attachment: caster / hand_r / weapon_tip / projectile / target / world
  quality: low / medium / high
  platform_fallbacks
  metadata: author, source_license, version
```

Ресурсы должны проходить валидацию (диапазоны, нулевые длительности, отсутствующие материалы, циклические зависимости, слишком много частиц, несовместимые режимы).

### 4.3. Runtime

- Один лёгкий `VFXManager`/сервис (либо расширение существующего) с `spawn`, `attach`, `stop`, `recycle`, без жёсткой привязки к конкретным навыкам.
- Пул экземпляров для частых эффектов; лимиты одновременно активных эффектов и источников света.
- Детерминированный seed для внешнего вида; **сетевую синхронизацию** делать через ID события/эффекта, позицию, направление, seed и время, без пересылки состояния каждой частицы.
- Автоматическое завершение и очистка; отсутствие утечек и зависших узлов.
- LOD по расстоянию, экранной значимости и качеству устройства. Для дальних игроков и массовых боёв — упрощённые варианты.
- Для dedicated server/headless — никакой зависимости от рендеринга.

### 4.4. Конструктор слоёв

Комбинировать: `GPUParticles3D`/`CPUParticles3D` (по реальной поддержке), mesh rings, billboard quads, flipbook spritesheets, procedural trails/ribbons, impact decals, shader dissolve, emissive meshes, кратковременный свет, screen-space эффекты **только если доступны на Android**, опциональные звуковые хуки. Не использовать дорогостоящие эффекты по умолчанию.

### 4.5. Библиотека архетипов

Обязательные категории v1:

| Категория | Архетипы |
|---|---|
| Огонь | fireball, flame burst, explosion, burning aura, flame trail |
| Вода/лёд | water splash, water wave, ice shards, frost nova, frozen mist |
| Земля | dust impact, rock shards, ground spike, ground shockwave, falling debris |
| Молния | lightning bolt, chain lightning, electric aura, spark hit |
| Свет | heal burst, blessing halo, holy beam, shield, purification |
| Тьма/некромантия | shadow projectile, cursed sigil, soul drain, undead summon, emerald curse |
| Оружие | sword slash arc, axe cleave, dagger stab, blunt hit, arrow impact, magic weapon trail |
| Существа/окружение | ghost apparition, dissolve, smoke, fog, toxic pool, ritual circle, portal, water droplets |

**Первые демонстрационные сцены:** минимум 12 качественных готовых пресетов, охватывающих все категории. После проверки — расширить до 30+ через вариации. Не обещать 200 уникальных эффектов до появления устойчивого генератора.

## 5. Художественный стиль Dark Pact

- Оригинальная anime fantasy cel-shaded эстетика: крупные читаемые формы, мягкие градиенты, умеренные контуры, минимум визуального шума на маленьком экране.
- Цвета по стихиям; не превращать всё в одинаковые белые вспышки.
- **Секта Мрака / подземелье:** кислотно-изумрудное свечение `#39FF8A` только для ритуалов, душ, проклятий, печатей и заражённой воды; скалы/мох/обычная слизь остаются приглушёнными. Дополнительные цвета — тёмный бирюзовый, фиолетовый, чёрный.
- Знаки культа — абстрактный глаз с щупальцами, спирали; не использовать буквы.
- Эффекты не должны скрывать силуэты врагов, телеграфы опасных атак и область взаимодействия.
- Важное различие: каст (на персонаже), полёт снаряда, попадание, длительный статус, завершение. Эти этапы должны быть независимыми слоями.

## 6. Приоритет Android и производительности

Тестовые устройства: Samsung Galaxy S24 Ultra; при доступности — Galaxy Tab S10 FE Plus. Целевые цифры **назначить после профилирования**, а не выдумывать. Проверять не только средний FPS, но и 1% low, кадры с пиками, память, нагрев и расход батареи.

Тестовые сценарии:
1. Один персонаж и одно заклинание.
2. 4 игрока одновременно кастуют разные эффекты.
3. 10–20 персонажей/мобов в бою с повторяющимися ударами.
4. Массовый бой с дымом, туманом, водой и зелёными ритуальными эффектами.
5. Длительная сессия 15–30 минут на реальном Android.

Для каждого эффекта: low/medium/high и мобильный fallback; лимиты overdraw, прозрачных слоёв, динамических источников света, числа материалов, draw calls, шейдерных вариантов и размера текстур. **Не использовать тяжёлую volumetric-симуляцию или real-time физику разрушений на телефоне**; запекать в flipbook/меши/простые частицы в Blender.

## 7. Blender как опциональная фабрика сложных эффектов

Blender не должен быть необходим для запуска игры. Он нужен для подготовки ресурсов:
- запекание сложных взрывов, огня, дыма, водяных всплесков в spritesheet/flipbook;
- подготовка низкополигональных осколков, камней, кусков земли;
- baked dissolve/появление призрака и ритуальных эффектов;
- экспорт оптимизированных GLB/текстур и создание импортных пресетов для Godot.

Отдельный pipeline: `Blender asset -> bake/export -> validate -> Godot import -> VFXPreset -> Android test`. Не предполагать, что Alembic/VAT/FBX-анимации автоматически корректно работают в Godot 4.3: проверять на минимальном образце. Поддержка Blender 5.x должна проверяться по установленной версии.

## 8. Интеграция с игровыми механиками

- Анимация персонажа определяет окно каста/удара; VFX слушает события анимации или боевой логики, но не решает, нанесён ли урон.
- Для оружия — точки крепления на реальных скелетах и костях; учитывать классы, пол и оружие (меч, топор, кинжал, посох, лук, арбалет и др.).
- Для навыков — таблица `skill_id -> cast_vfx / projectile_vfx / impact_vfx / buff_vfx` с возможностью переопределения по классу и стихии.
- Для питомцев и монстров — общая библиотека архетипов с масштабированием и цветовыми вариациями.
- Для подземелья «Тёмный пакт» — ритуальные круги, зелёный туман, призраки, всплывающая нежить, ядовитая вода, эффект двух фаз капитана, телеграфы атак.
- Отдельно проверить повторное использование эффектов при быстром спаме навыков, отмене каста, смерти цели, смене сцены и переподключении клиента.

## 9. Этапы работ и контрольные точки

**Этап A — аудит и план.** Изучить код и зависимости, составить таблицу оценки сторонних проектов (включая лицензии), предложить точные пути и точки интеграции. Отчитаться до масштабных изменений.

**Этап B — минимальное ядро.** Ресурс пресета, генератор слоёв, предпросмотр, сохранение сцены, VFXManager, pooling, один простой spell и один weapon hit.

**Этап C — архетипы.** 12 демонстрационных пресетов, настройка цвета/размера/длительности, LOD, batch generation.

**Этап D — интеграция.** Привязка к реальным skill/animation events, поддержка питомцев, монстров и окружения, эффекты Dark Pact.

**Этап E — оптимизация.** Профилирование Android, low/medium/high, деградация качества при нагрузке, стресс-тесты, фиксы.

**Этап F — документация.** Руководство художника, руководство разработчика, таблица пресетов, лицензии/NOTICE, инструкции по добавлению эффекта без правки кода ядра.

## 11. Приёмка

- Генератор открывается в версии Godot проекта без ошибок.
- Пользователь создаёт новый эффект из архетипа, меняет цвет/размер/длительность, видит предпросмотр, сохраняет, закрывает редактор, открывает и воспроизводит тот же эффект.
- Сохранённый эффект запускается по игровому событию и автоматически освобождает ресурсы.
- 12 демонстрационных пресетов визуально различимы и не являются просто перекрашенным одним emitter.
- Есть вариант low для каждого эффекта, нет критических ошибок в headless и Android-сборках (APK **не собирать без разрешения**).
- Никаких изменений урона, баланса, таймингов атак, логики квестов и сетевой истины.
- Все зависимости документированы; отсутствие необязательного Blender/AI/плагина не мешает работе базовой системы.
- Все изменения ограничены согласованным объёмом, легко откатываются; существующие VFX продолжают работать.
