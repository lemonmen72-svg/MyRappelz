# Эффекты умений — как пользоваться

## Как появляются эффекты
1. Правила `vfx/vfx_rules.gd` читают умение: название, описание, стихию, вид применения, действия.
2. Генератор пишет таблицу: `godot --headless --path . res://tools/vfx_generate.tscn` → `vfx/skill_vfx.json` и каталог
   `docs/vfx/VFX_PRESETS_CATALOG.md` (что у какого умения).
3. Игра по событию боя (каст, выпуск, попадание, усиление) строит эффект фазы.

## Новое умение
Ничего делать не нужно: запустить генератор — у умения появятся эффекты по его стихии и виду. Тест
`tests/test_vfx_gen.gd` упадёт, если таблица устарела, — тогда запустить генератор.

## Поправить эффект руками
`vfx/skill_vfx_overrides.json`, например:
```json
{"hero": {"fire_spark": {"impact": {"arch": "explosion", "scale": 0.8}}},
 "pet": {"wolf:chilling_howl": {"el": "ice", "release": {"el": "ice"}}}}
```
Поля фазы дополняют сгенерированные; `"impact": null` — убрать фазу. Архетипы и палитры — `VFX_PRESETS_CATALOG.md`.

## Новый архетип
Функция `_a_<имя>(P)` в `vfx/vfx_archetypes.gd` из слоёв `VfxKit`, строка в `VfxArchetypes.LIST`, ветка в `match` функции `build`,
правило в `VfxRules`, затем генератор.

## Откат
Админ-панель → «Тест-бот» → «Эффекты» → «Новые эффекты умений: выкл.» — везде прежние вспышки.
