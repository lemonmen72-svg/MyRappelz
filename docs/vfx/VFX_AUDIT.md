# Dark Pact — аудит эффектов (этап A генератора VFX)

Дата: 06.11.2026. Основа — код ветки на 0.40.0 и ТЗ `DARK_PACT_UNIVERSAL_VFX_GENERATOR_CLAUDE.md`.

## 1. Что уже есть

### 1.1. `vfx.gd` (`Vfx`) — библиотека эффектов (561 строка)
- Статические функции-эффекты: `hit_spark`, `slash_arc`, `heal_sparkles`, `level_up`, `tame_success`, `evolution`,
  `pickup`, `magic_burst`, `death_puff`, `ambient_sparkles`.
- Строительные блоки: `_root` (узел в группе `vfx`, удаляется твином через life), `_sprite` (билборд-вспышка),
  `_ground_ring` (кольцо на земле), `_glow_sphere`, `_pillar` (столб света), `_spiral`, `_particles` (CPUParticles3D
  с параметрами: форма, разлёт, гравитация, затухание, кривая размера), `_arc_mesh` (дуга удара).
- Текстуры рисуются кодом (`tex`: star, ring, puff, spark …), материалы — `fx_mat` (unshaded, аддитивные/альфа,
  билборд), кэш мешей, кривых, градиентов.
- Число частиц — `Quality.particles(n)` (настройка «Эффекты»).
- Только CPUParticles3D: одинаково работают в Compatibility (OpenGL ES) и Mobile (Vulkan).
- Пула нет: каждый эффект — новые узлы и материалы, удаление `queue_free` по таймеру.

### 1.2. Кто вызывает (≈ 160 вызовов из 24 файлов)
| Где | Что |
|---|---|
| `hero_skill_fx.gd` | урон умения: `slash_arc` (ближний бой) или `hit_spark`; «self»/«pet» — `Projectile.burst` |
| `job_fx_*.gd` (8 профессий) | `magic_burst`, `hit_spark` — зоны, молнии, лечение, особые механики |
| `projectile.gd` | полёт: стрела, болт, магический сгусток (меши + `fx_mat` + `ambient_sparkles`), попадание `hit_spark` |
| `pet.gd`, `pet_bond.gd` | умения питомца, ауры, «Омут порчи», лечение |
| `mob.gd` | удар по площади (`slam`: круг-телеграф + `death_puff` + `magic_burst`), проклятие капитана, приручение, смерть |
| `player.gd`, `main.gd` | уровень, подбор, смерть |
| `portal.gd` + `portal.gdshader` | портал (шейдер, свет) — самостоятельный эффект |

### 1.3. Данные, к которым можно привязать эффекты
- Умения героя (`JobSkills`, `HeroSkills`): поле `c` — стихия/тема (fire 13, light 20, heal 12, dark 11, earth 13,
  water 8, storm 6, wind 7, blood 8, spirit 10, mind 10, steel 15, shield 8, beast 15), `color`, `use`
  (melee / ranged / magic / near / self / pet), `anim` (attack, bash, buff, cast, dash, spin), `proj`.
  Этого хватает, чтобы **без ручной разметки** каждому умению выбрать архетип по стихии и виду применения,
  а вручную переопределять только особые.
- События боя уже существуют как места вызова: начало каста (`Player._begin_cast`), выпуск (`_finish_cast`),
  выстрел (`Player._shoot` → `Projectile`), попадание (`Projectile` / `HeroSkillFx.apply`), усиление
  (`add_timed_bonus`), смерть (`Mob.die`), призыв питомца (`PetManager._spawn`), удар зверя по площади, проклятие.
- Урон и тайминги считает логика (`Player`, `HeroSkillFx`, `Mob`) по игровому времени; эффекты — только картинка.
  Это остаётся так: генератор ничего в бою не меняет.

### 1.4. Рендер и качество
- Рендерер: Mobile (Vulkan) на телефонах с нормальным Vulkan (S24 Ultra), запасной Compatibility; CI — Compatibility.
- `Quality`: пресеты, настройка «Эффекты» (доля частиц), `ThermalGuard` снижает графику при нагреве.
- Экранные эффекты: свой `postfx.gdshader` (цвет, свечение, FXAA). Отдельных экранных эффектов для VFX не нужно.
- Свет: динамические OmniLight только у портала и огней подземелья (`DungeonProps.MAX_LIGHTS` 10).

### 1.5. Чего нет
- Данных-пресетов (эффект описан только кодом функции), редактора, предпросмотра, сохранения.
- Пула и общего лимита одновременных эффектов; LOD по расстоянию для эффектов.
- Таблицы «умение → эффект каста / снаряда / попадания / усиления»: у всех умений эффект общий, различается только цвет.
- Эффектов фаз «каст на герое» и «длительное усиление» (кроме значков и `ambient_sparkles`).

## 3. Риски
- **Максим работает с телефона** — редактор в Godot на ПК (EditorPlugin из ТЗ) он открыть не может. Нужна
  студия **внутри игры** (как редактор расстановки подземелья), а EditorPlugin — по желанию позже.
- Прозрачность и перерисовка (overdraw) на телефоне: много больших билбордов в бою греют видеочип. Нужны лимиты
  и упрощённые варианты на «Низком» и при нагреве (`ThermalGuard`).
- GPUParticles3D в Compatibility 4.3 есть, но поведение и стоимость на старых телефонах хуже; остаёмся на
  CPUParticles3D (малые количества, считаются на процессоре).
- Замена эффектов у 160 вызовов — поэтапно: старые функции `Vfx` остаются и работают; новые эффекты подключаются
  через таблицу привязок, откат — одна настройка.
- Замер на телефоне — только через тест-бота (раздел в отчёте); без него в `VFX_ANDROID_BENCHMARK.md` — «не проверено».
