# MyRappelz: прототип 3D-MMO в духе Rappelz (офлайн)

Godot 4.3+, рендерер GL Compatibility. Вся графика: простые фигуры-заглушки.

## Запуск на ПК
1. Установить Godot 4.3 или новее: https://godotengine.org
2. Project Manager → Import → выбрать `project.godot`
3. F5

Управление на ПК: WASD / стрелки: ходьба, Пробел: атака, T: приручить.
На телефоне: левая половина экрана: джойстик, справа кнопки «Атака» и «Приручить».

## Что есть
- Мир: равнина с деревьями
- Игрок: ходьба, атака мечом, уровни, золото, регенерация
- Звери: Кабан, Волк, Медведь. Блуждают, агрятся, возвращаются домой, респавн через 20 с
- Приручение: ослабить зверя ниже 50% HP, подойти и нажать «Приручить» (шанс 65%)
- Питомец: идёт за вами, помогает в бою, получает опыт и уровни, при потере HP отдыхает 10 с

## Сборка под Android
APK собирается в GitHub Actions **только вручную**: Actions → «Сборка APK» → Run workflow.
Готовый файл публикуется в Releases. На каждый пуш запускается только автотест («Проверка кода»).

Локально: Godot 4.3 → Editor → Manage Export Templates → Download, указать Android SDK и JDK 17
в Editor Settings → Export → Android, затем Project → Export → Android.

## Структура
- `main.gd`: мир, спавн, приручение, камера
- `player.gd`, `mob.gd`, `pet.gd`: персонаж, звери, питомец
- `hud.gd`: сенсорное управление и интерфейс
- `util.gd`: общие функции
- `tests/smoke_test.gd`: автотест без экрана
- `export_presets.cfg`, `android/`, `.github/`: сборка APK
