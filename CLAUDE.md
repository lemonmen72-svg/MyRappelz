# Проект: своя 3D-игра в духе Rappelz Online (Android)

Стартовый контекст для сессий Claude Code. Язык общения с пользователем (Максим): русский.

## ⛔ Главное правило: сборка APK только по команде
- **Не собирать APK без прямой команды Максима.** Это касается и запуска workflow «Сборка APK»
  (`.github/workflows/android-apk.yml`), и локального экспорта Godot под Android, и создания релизов.
- Команда должна быть явной («собери APK», «сделай релиз» и т. п.) и относится только к одной сборке.
  Разрешение на прошлую сборку не переносится на следующую.
- Без команды можно: править код, коммитить, пушить, запускать автотест (workflow «Проверка кода»).
- Workflow сборки APK запускается только вручную: кнопкой Run workflow, пушем тега `v<версия>`
  или изменением версии в `android/release_version.txt`. Других триггеров (обычный push, PR, расписание) у него быть не должно.
- Claude не может нажать Run workflow (нет прав у интеграции) и пушить теги (прокси сессии),
  поэтому по команде Максима поднимает версию в `android/release_version.txt`, коммитит и пушит.
  Без команды этот файл и теги `v*` не трогать.

## Идея
Максим делает свою игру, похожую на Rappelz Online, под Android.
Главный ориентир по механикам: официальный сайт игры https://rz.gamexp.com/ — на него опираемся почти во всём
(классы, расы, система питомцев, умения, баланс, интерфейс, устройство мира).
Но это не копия: графику, модели, музыку, тексты, названия, персонажей и карты Rappelz использовать нельзя
(авторское право и товарный знак). Берём механики и общую структуру, всё содержимое своё и оригинальное.

## Решения, принятые с пользователем
- Платформа: Android. Движок: Godot 4.3 (GDScript), рендерер GL Compatibility. Графика: 3D.
- Начинаем офлайн, без сервера и мультиплеера. Приоритеты: бой, питомцы, мир.
- Сервер и мультиплеер: позже, когда основа станет играбельной.

## Структура репозитория
Проект Godot лежит в корне репозитория (плоская структура).

### Ядро (общее, меняется только согласованно)
- `project.godot`: настройки, автозагрузка `Game`, горизонтальная ориентация, касания ↔ мышь, ETC2/ASTC.
- `game_state.gd` (автозагрузка `Game`): персонаж (имя, раса, класс, уровень, опыт, золото), сумка
  (`Inventory`), коллекция питомцев `Game.pets` (записи-словари), `active_pet`, сохранение `user://save.json`.
- `main.tscn` + `main.gd`: создание персонажа → мир, игрок, звери по слотам, модули, кнопки HUD,
  маршрутизация действий HUD в модули (`handle_action`), события убийства зверя (`on_mob_killed`), автосохранение.
- `hud.gd`: джойстик, круглые кнопки (`add_button`, `is_held`, `set_cooldown`), окна (`create_window`),
  панели игрока, питомца и цели, сообщения.
- `util.gd`: материалы, поиск ближайшего, тело зверя из коробок, всплывающий текст, тема UI `Util.ui_theme()`.
- `inventory.gd`: сумка (id предмета → количество).

### Модули
- Персонаж и бой: `data_classes.gd` (`ClassData`: расы, классы, умения), `player.gd`, `projectile.gd`
  (снаряды лука и магии), `character_create.gd` (с 3D-превью), `character_model.gd` (`CharacterModel`:
  аниме-модель персонажа и торговца, анимации). Тесты `tests/test_combat*.gd`, `tests/test_character_model.gd`.
- Питомцы и звери: `data_mobs.gd` (`MobData`), `data_pets.gd` (`PetData`: роли, стадии эволюции),
  `creature_models.gd` (модели зверей), `mob.gd`, `pet.gd`, `pet_manager.gd` (призыв, команды, окно), `taming.gd`.
  Тесты `tests/test_pets*.gd`.
- Графика: `util.gd` (toon-материалы, `toonify_mesh`, контуры), `outline.gdshader`, `vfx.gd` (`Vfx`: эффекты),
  `world_builder.gd` + шейдеры мира (`sky`, `terrain`, `grass`, `flower`, `flag`, `world_common.gdshaderinc`).
  Тест `tests/test_vfx.gd`, скриншоты `tests/shots.gd` (CI-задача visual → ветка `ci-screenshots`).
- Мир (тренировочный остров): `world/training_island.json` (конфиг: река, дороги, точки интереса, зоны, спауны),
  `island_world.gd` (`IslandWorld`: рельеф, коллизия, проходимость, мосты, запросы), `island_water.gd`, `island_pois.gd`,
  `island_vegetation.gd` (+ `island_grass`/`island_flower`/`veg_outline` шейдеры), `island_shore.gd`,
  `water.gdshader`, `island_terrain.gdshader`, `tools/extract_island_masks.py`, референсы в `reference/`.
  Подробно — `world/README.md`. Тесты `tests/test_island.gd`, `tests/test_vegetation.gd`.
- Качество и постобработка: `quality.gd` (`Quality`: Low/Medium/High в `user://settings.cfg`), `postfx.gd` + `postfx.gdshader`,
  `settings_menu.gd` (окно «Настройки» в HUD).
- Предметы и торговля: `data_items.gd` (`ItemData`), `economy.gd` (добыча, сумка, магазин, зелья),
  `merchant.gd` (торговец и круг безопасной зоны), `loot_drop.gd` (мешочек с добычей). Тест `tests/test_economy.gd`.

### Прочее
- `icon.svg`: иконка приложения (своя).
- `export_presets.cfg`: пресет «Android» (пакет `com.lemonmen.myrappelz`, armeabi-v7a + arm64-v8a, без Gradle).
- `tests/test_base.gd`: основа автотестов; `tests/smoke_test.gd` и `tests/test_*.gd`: сценарии.
- `android/dev.keystore`: ключ разработчика (alias `myrappelz`, пароль `myrappelz-dev`). Для Google Play нужен свой ключ в секретах.
- `.github/workflows/check.yml`: все автотесты на каждый пуш (APK не собирает).
- `.github/workflows/android-apk.yml`: сборка APK и релиз, только вручную.

## Механики (ориентир: гайды rz.gamexp.com, своё оформление)
- Расы: Люди (Воин, Следопыт), Светлые эльфы (Страж, Жрец), Тёмные эльфы (Убийца, Чернокнижник).
- Звери: Кабан, Волк, Медведь (обычные), Лесная фея, Искрожук (редкие), Каменный страж (уникальный).
- Приручение: кристалл души (обычный/редкий/древний) + умение «Приручить» на цель, затем зверя добить; успех по шансу,
  при неудаче кристалл ломается. Коллекция до 6 питомцев, призван один.
- Питомцы: роли (танк, боец, маг, лекарь), 3 стадии эволюции, команды «Атакуй» / «За мной», воскрешение свитком.
- Безопасные зоны (город, деревни, порт) из конфига острова: звери туда не заходят. Торговец в городе.
- Игрок стартует и возрождается в деревне своей расы. Камера от третьего лица, вращается перетаскиванием.
- Слои коллизий: мир = слой 1; игрок, звери и питомцы = слой 2, маска 1.

## Графика: стиль аниме cel-shading (в духе Genshin Impact)
Решение Максима: стиль как у Genshin Impact. Сам стиль (cel-shading, контуры, яркие цвета) использовать можно,
чужие персонажи и ассеты — нельзя.
- Шейдеры пишем свои под Godot (toon/cel: ступенчатый свет, rim, контур). Проекты под Unity/Blender
  (GenshinCelShaderURP, Blender-miHoYo-Shaders) — только как справка по технике, код не копировать без проверки лицензии.
- Нельзя: datamined-ассеты miHoYo (например rayshire/GI_Assets), фанатские модели персонажей Genshin со Sketchfab
  и любые узнаваемые персонажи Genshin/Rappelz — это чужая интеллектуальная собственность, даже если лицензия на сайте «свободная».
- Можно: свои аниме-аватары из VRoid Studio (импорт VRM в Godot), CC0-ассеты (gobkit, Quaternius, Kenney),
  бесплатные ассеты itch.io с лицензией, разрешающей коммерческое использование (проверять каждый),
  модели из AI-генераторов (Tripo, Meshy, Hunyuan3D, hi3d, assetfurnace) по своим оригинальным эскизам — с проверкой их условий.
- Для каждого внешнего ассета записывать источник и лицензию в `assets/LICENSES.md`.

## Проверка и сборка
- Автотест локально: `godot --headless --path . --import`, затем
  `godot --headless --fixed-fps 60 --path . res://tests/runner.tscn -- res://tests/smoke_test.gd`
  (каждый тест должен вывести `TEST OK`).
  Godot в облачной сессии Claude запускать не разрешено — проверка идёт в CI (workflow «Проверка кода»).
- APK (только по команде Максима): GitHub → Actions → «Сборка APK» → Run workflow с версией,
  или `git tag v0.1.1 && git push origin v0.1.1`, или новая версия в `android/release_version.txt`. Готовый APK появляется в Releases (тег `v<версия>`).
  Для каждой новой сборки — новая версия/тег.
- Свой ключ подписи: секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_USER`, `ANDROID_KEYSTORE_PASSWORD`.
  Внимание: APK с другим ключом не встанет поверх старого, нужно удалить прежнюю версию.

   сервер и мультиплеер (не согласовано).
