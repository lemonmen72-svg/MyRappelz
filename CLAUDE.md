# Проект: своя 3D-игра в духе Rappelz Online (Android)

Стартовый контекст для сессий Claude Code. Язык общения с пользователем (Максим): русский.

## ⛔ Главное правило: сборка APK только по команде
- **Не собирать APK без прямой команды Максима.** Это касается и запуска workflow «Сборка APK»
  (`.github/workflows/android-apk.yml`), и локального экспорта Godot под Android, и создания релизов.
- Команда должна быть явной («собери APK», «сделай релиз» и т. п.) и относится только к одной сборке.
  Разрешение на прошлую сборку не переносится на следующую.
- Без команды можно: править код, коммитить, пушить, запускать автотест (workflow «Проверка кода»).
- Workflow сборки APK запускается только вручную: кнопкой Run workflow, пушем тега `v<версия>`
  или изменением версии в `android/release_version.txt`. Других триггеров (обычный push, PR, расписание) у него быть не должно.
- Claude не может нажать Run workflow (нет прав у интеграции) и пушить теги (прокси сессии),
  поэтому по команде Максима поднимает версию в `android/release_version.txt`, коммитит и пушит.
  Без команды этот файл и теги `v*` не трогать.

## Идея
Максим делает свою игру, похожую на Rappelz Online, под Android.
Главный ориентир по механикам: официальный сайт игры https://rz.gamexp.com/ — на него опираемся почти во всём
(классы, расы, система питомцев, умения, баланс, интерфейс, устройство мира).
Но это не копия: графику, модели, музыку, тексты, названия, персонажей и карты Rappelz использовать нельзя
(авторское право и товарный знак). Берём механики и общую структуру, всё содержимое своё и оригинальное.

## Решения, принятые с пользователем
- Платформа: Android. Движок: Godot 4.3 (GDScript), рендерер GL Compatibility. Графика: 3D.
- Начинаем офлайн, без сервера и мультиплеера. Приоритеты: бой, питомцы, мир.
- Сервер и мультиплеер: позже, когда основа станет играбельной.

## Структура репозитория
Проект Godot лежит в корне репозитория (плоская структура).

### Ядро (общее, меняется только согласованно)
- `project.godot`: настройки, автозагрузка `Game`, горизонтальная ориентация, касания ↔ мышь, ETC2/ASTC.
- `game_state.gd` (автозагрузка `Game`): персонаж (имя, раса, класс, уровень, опыт, золото), сумка
  (`Inventory`), коллекция питомцев `Game.pets` (записи-словари), `active_pet`, сохранение `user://save.json`.
- `main.tscn` + `main.gd`: создание персонажа → мир, игрок, звери по слотам, модули, кнопки HUD,
  маршрутизация действий HUD в модули (`handle_action`), события убийства зверя (`on_mob_killed`), автосохранение.
- `hud.gd`: джойстик, круглые кнопки (`add_button`, `is_held`, `set_cooldown`), окна (`create_window`),
  панели игрока, питомца и цели, сообщения.
- `util.gd`: материалы, поиск ближайшего, тело зверя из коробок, всплывающий текст, тема UI `Util.ui_theme()`.
- `inventory.gd`: сумка (id предмета → количество).

### Модули
- Персонаж и бой: `data_classes.gd` (`ClassData`: расы, классы, умения), `player.gd`, `projectile.gd`
  (снаряды лука и магии), `character_create.gd` (с 3D-превью), `character_model.gd` (`CharacterModel`:
  аниме-модель персонажа и торговца, анимации). Тесты `tests/test_combat*.gd`, `tests/test_character_model.gd`.
- Модели персонажей из файлов: `assets/characters/` (glTF из Meshy со скелетом Mixamo и анимациями, текстура рядом PNG,
  `.import` с отключёнными встроенными картинками). `CharacterModel` грузит их, если в параметрах есть `asset`.
  Сейчас одна модель — главный герой (тёмная эльфийка-Бродяга `dark_elf_wanderer.glb`), она у всех рас и классов,
  пока Максим не сделает остальных; своя модель задаётся полем `"model"` у класса или расы в `ClassData`.
  Источники и лицензии — `assets/LICENSES.md`.
  Дополнительные анимации героя (Idle, удары и комбо мечом, рывок, кувырок, урон, смерть, каст, подбор) —
  из Quaternius Universal Animation Library 1 и 2 (CC0), перенесены на скелет Mixamo оффлайн скриптом
  `tools/retarget_animations.py` и записаны прямо в GLB героя. Новая модель героя на том же скелете:
  скачать «…[Standard].zip» с quaternius.itch.io/universal-animation-library и …-library-2, затем
  `python3 -I tools/retarget_animations.py --ual1 <UAL1_Standard.glb> --ual2 <UAL2_Standard.glb> assets/characters/<герой>.glb`
  (`--check` — без записи; повторный запуск заменяет свои клипы). Какой клип играет какое действие —
  `ASSET_ACTIONS` / `ASSET_IDLE` в `character_model.gd`.
- Звери из файлов: `assets/creatures/<id>.glb` + `<id>.png` (пантера `panther`, черепаха `turtle`, фазан `pheasant`;
  Meshy AI, сделаны Максимом). Скрипт `tools/prepare_creatures.py` (numpy, Pillow, meshoptimizer) из GLB Meshy со скелетом
  без анимаций делает: меш ~7 тыс. треугольников, реальный размер (высота в `CREATURES`), морда в +Z, ноги на y = 0,
  понятные имена костей (Root, Hips, Chest, Neck*, Head, Tail*, LegFL1…/LegL1…, Wing*), процедурные клипы
  Idle/Walk/Run/Attack/Hit/Death/Cast (корень по X/Z на месте), `assets/creatures/creatures.json` — размеры, скорости шага
  и бега без проскальзывания, длины клипов, момент удара (`attack_hit_time`) и умения (`cast_time`), роли костей.
  Новый зверь или стадия эволюции: запись в `CREATURES` в скрипте (высота, стиль «cat»/«turtle»/«bird», шаг), затем
  `python3 -I tools/prepare_creatures.py <id>=<файл.glb>` (`--check` — только проверка готовых, `--preview <папка>` — картинки).
- Питомцы и звери: `data_mobs.gd` (`MobData`: звери, редкость, перевод старых id), `data_pets.gd` (`PetData`: роли,
  стадии эволюции), `creature_models.gd` (модели зверей из примитивов: слитый меш на скелете + `creature.gdshader`,
  `creature_outline.gdshader`; запасные модели пантеры, черепахи и фазана), `creature_asset.gd` (`CreatureAsset`: зверь
  или питомец из файла — модель Meshy со скелетом, клипы Idle/Walk/Run/Attack/Hit/Death/Cast, свой toon-материал,
  украшения питомца), `mob.gd`, `pet.gd`, `pet_manager.gd` (призыв, команды, окно), `taming.gd`.
  Модели зверей из файлов: `assets/creatures/<id>.glb` + `<id>.png` + `creatures.json` (размеры, скорости клипов,
  момент удара); нет файла — `CreatureModels` строит запасную модель из примитивов. Тесты `tests/test_pets*.gd`.
- Характеристики и умения питомцев (по образцу Rappelz Pantera/Tortus/Poultry, названия свои): `pet_stats.gd`
  (`PetStats`: 7 статов по таблицам вики по уровню и стадии, обмен статов под роль, все формулы производных —
  HP, MP, физ./маг. атака, лечение, защиты, точность, уклонение, крит, скорость атаки, восстановление; калибровка
  вида под прежний баланс), `data_pet_skills.gd` (`PetSkills`: умения, уровни по стадиям, JP, требования, бонусы,
  тексты), `creature_window.gd` (`CreatureWindow`: окно существа, вкладки «Существо» и «Умения», живёт в
  `PetManager.creature`). Справка и расчёт баланса — `tools/rappelz_pet_reference.md`. Тест `tests/test_pet_skills.gd`.
- Графика: `util.gd` (toon-материалы, `toonify_mesh`, контуры), `outline.gdshader`, `vfx.gd` (`Vfx`: эффекты),
  `world_builder.gd` + шейдеры мира (`sky`, `terrain`, `grass`, `flower`, `flag`, `world_common.gdshaderinc`).
  Тест `tests/test_vfx.gd`, скриншоты `tests/shots.gd` (CI-задача visual → ветка `ci-screenshots`).
- Рисованные текстуры окружения: `world_textures.gd` (`WorldTextures`: загрузка, номера текстур, флаги по качеству),
  PNG в `assets/textures/` (их делает `tools/gen_textures.py`). Тест `tests/test_textures.gd`.
- Мир (тренировочный остров): `world/training_island.json` (конфиг: река, дороги, точки интереса, зоны, спауны),
  `island_world.gd` (`IslandWorld`: рельеф, коллизия, проходимость, мосты, запросы), `island_water.gd`, `island_pois.gd`,
  `island_pois.gd` + `poi_models.gd` (`PoiModels`: модели-заглушки построек, одна функция на тип) + `poi_anim.gd`,
  `toon.gdshader`, `crystal.gdshader`, `island_vegetation.gd` (+ `island_grass`/`island_flower`/`veg_outline` шейдеры), `island_shore.gd`,
  `water.gdshader`, `island_terrain.gdshader`, `tools/extract_island_masks.py`, референсы в `reference/`.
  Подробно — `world/README.md`. Тесты `tests/test_island.gd`, `tests/test_vegetation.gd`, `tests/test_pois.gd`.
- Качество и постобработка: `quality.gd` (`Quality`: Low/Medium/High в `user://settings.cfg`), `postfx.gd` + `postfx.gdshader`,
  `settings_menu.gd` (окно «Настройки» в HUD).

  `merchant.gd` (торговец и круг безопасной зоны), `loot_drop.gd` (мешочек с добычей). Тест `tests/test_economy.gd`.

## Механики (ориентир: гайды rz.gamexp.com, своё оформление)
- Расы: Люди (Воин, Следопыт), Светлые эльфы (Страж, Жрец), Тёмные эльфы (Бродяга — id `assassin`, Чернокнижник).
- Звери: Кабан, Волк, Пантера (маг), Черепаха (танк), Фазан (лекарь) — «Базовые» (в коде редкость `common`);
  Каменный страж (уникальный). Пантера, черепаха и фазан — модели из файлов (`CreatureAsset`); заменили медведя,
  искрожука и фею (старые сохранения переводятся при загрузке: bear→panther, sparkbug→turtle, fairy→pheasant,
  трофеи тоже). Редкость `rare` в коде осталась (пока без зверей).
- Приручение: кристалл души (базовый/редкий/древний) + умение «Приручить» на цель, затем зверя добить; успех по шансу,
  при неудаче кристалл ломается. Коллекция до 6 питомцев, призван один.
- Питомцы: роли (танк, боец, маг, лекарь), 3 стадии эволюции, команды «Атакуй» / «За мной», воскрешение свитком.
- Характеристики питомца: Сила, Выносливость, Ловкость, Интеллект, Мудрость, Меткость, Удача (таблицы вики,
  уровень вики = наш × 1/0.3; пантера-маг: Сила ↔ Интеллект, фазан-лекарь: Меткость ↔ Мудрость), из них HP, MP,
  атаки и пр. (`PetStats.derived`). У питомца есть MP (полоска в HUD) и его восстановление.
- Умения питомца: изучаются за JP в окне существа (кнопка «Подробнее» в «Питомцах», «Существо» у панели питомца, C).
  JP: 2 у нового + 3 за уровень опыта (копятся за убийства). До 15 ур. умения: 1–5 на 1-й стадии, 6–10 на 2-й,
  11–15 на 3-й; требуемый уровень вики × 0.3; пререквизиты. Активные применяет ИИ (урон от главной атаки роли,
  MP, перезарядка; оглушение, замедление, морок, уязвимость, промахи зверя), переключаемые («Узы …», «Дерзкий вызов»)
  включаются в окне и тратят MP раз в 10 с, пассивные — всегда. Запись питомца: `jp`, `jp_part`, `skills`, `toggles`, `mp`.
- Безопасные зоны (город, деревни, порт) из конфига острова: звери туда не заходят. Торговец в городе.
- Игрок стартует и возрождается в деревне своей расы. Камера от третьего лица, вращается перетаскиванием.
- Слои коллизий: мир = слой 1; игрок, звери и питомцы = слой 2, маска 1.

## Графика: стиль аниме cel-shading (в духе Genshin Impact)
Решение Максима: стиль как у Genshin Impact. Сам стиль (cel-shading, контуры, яркие цвета) использовать можно,
чужие персонажи и ассеты — нельзя.
- Шейдеры пишем свои под Godot (toon/cel: ступенчатый свет, rim, контур). Проекты под Unity/Blender
  (GenshinCelShaderURP, Blender-miHoYo-Shaders) — только как справка по технике, код не копировать без проверки лицензии.
- Нельзя: datamined-ассеты miHoYo (например rayshire/GI_Assets), фанатские модели персонажей Genshin со Sketchfab
  и любые узнаваемые персонажи Genshin/Rappelz — это чужая интеллектуальная собственность, даже если лицензия на сайте «свободная».
- Можно: свои аниме-аватары из VRoid Studio (импорт VRM в Godot), CC0-ассеты (gobkit, Quaternius, Kenney),
  бесплатные ассеты itch.io с лицензией, разрешающей коммерческое использование (проверять каждый),
  модели из AI-генераторов (Tripo, Meshy, Hunyuan3D, hi3d, assetfurnace) по своим оригинальным эскизам — с проверкой их условий.
- Для каждого внешнего ассета записывать источник и лицензию в `assets/LICENSES.md`.
- Текстуры окружения (`assets/textures/`: трава, земля, песок, скала, брусчатка, доски, черепица, солома, штукатурка)
  свои: их генерирует `tools/gen_textures.py` (numpy + Pillow, фиксированное зерно, бесшовные 512×512).
  Это почти серые «детальные маски» со средним 0.5: шейдеры умножают цвет зоны/вершины на tex × 2, палитра сохраняется.
  Земля — `island_terrain.gdshader` (по мировым XZ, скалы triplanar), постройки — `toon.gdshader` (проекция по мировым
  координатам, номер текстуры детали — в альфе цвета вершины `PoiModels.Kit`, по палитре или `Kit.tex`).
  Включены на «Среднем» и «Высоком» (ключ `textures` в `Quality.PRESETS`), на «Низком» выборок нет.
  Поменять вид — правка скрипта и перезапуск `python3 tools/gen_textures.py`, PNG коммитить.

## Проверка и сборка
- Автотест локально: `godot --headless --path . --import`, затем
  `godot --headless --fixed-fps 60 --path . res://tests/runner.tscn -- res://tests/smoke_test.gd`
  (каждый тест должен вывести `TEST OK`).
  Godot в облачной сессии Claude запускать не разрешено — проверка идёт в CI (workflow «Проверка кода»).
- APK (только по команде Максима): GitHub → Actions → «Сборка APK» → Run workflow с версией,
  или `git tag v0.1.1 && git push origin v0.1.1`, или новая версия в `android/release_version.txt`. Готовый APK появляется в Releases (тег `v<версия>`).
  Для каждой новой сборки — новая версия/тег.
- Свой ключ подписи: секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_USER`, `ANDROID_KEYSTORE_PASSWORD`.
  Внимание: APK с другим ключом не встанет поверх старого, нужно удалить прежнюю версию.

## План
1. Механики: персонаж и бой, питомцы и приручение, предметы и торговец (готово, версия 0.2.0).
2. Графика в стиле аниме cel-shading (готово, версия 0.3.0; модели из примитивов, позже можно заменить на VRoid).
3. Мир, этап 1: тренировочный остров по `reference/training_island.png` (готово, версия 0.4.0; постройки — заглушки).
3a. Оптимизация под телефон и главный герой из Meshy (готово, версии 0.5.0–0.5.2: модели одним мешем на скелете,
   720p на «Низком»/«Среднем», предел кадров 30/45/60, приближение камеры щипком; Максим проверил — работает).
4. Дальше: материк (5 городов по `reference/world_map.png`), экипировка, квесты и NPC, слияние питомцев,
   сервер и мультиплеер (не согласовано).
