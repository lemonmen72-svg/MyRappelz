# Справочник баланса по базе и серверу оригинала (сборка сервера 2011 г.)

Источник — архив Максима `game_bin.rar` (Яндекс Диск): бэкап ресурсной базы `Arcadia.bak` (SQL Server 2008 R2:
таблицы `LevelResource`, `JobResource`, `JobLevelBonus`, `StatResource`, `MonsterResource`, `SummonResource`,
`CreatureLevelBonus`, `SummonLevelResource`, `ItemResource`, `SkillResource`, `DropGroupResource`, `EnhanceResource`, …)
и игровой сервер `CaptainHerlockServer.exe` с отладочными символами `.pdb` (GUID совпадает) — формулы ниже прочитаны
из его кода (`StructCreature::calcAttribute`, `CalculateStat`, `CalcDamage`, `GetCriticalDamage`, `GameRule::*`).
Сырые таблицы в репозиторий не кладём (чужие данные; репозиторий публичный) — здесь только числа для нашего баланса.
Как разобрать заново: восстановить `Arcadia.bak` в SQL Server (Linux, Developer), выгрузить таблицы в CSV; формулы —
`llvm-pdbutil dump --publics` + `llvm-objdump -d` по адресам функций.

## Формулы сервера (дословно)

Статы: Сила (str), Выносливость (vit), Меткость (dex), Ловкость (agi), Интеллект (int), Мудрость (men), Удача (luk);
L — уровень, FCM — множитель статов (герой и зверь 1.0; существо-питомец 0.7 + 0.03 × уровень пассивки хозяина
«мастерство существ», id 1811).

| показатель | формула |
|---|---|
| макс. HP | 30·vit·FCM + 20·L |
| макс. MP | 30·int·FCM + 20·L |
| физ. атака (ближний бой) | 2·str·FCM + L (+ оружие) |
| физ. атака (лук, арбалет) | (1.6·dex + 0.4·str)·FCM + L |
| маг. атака | 2·int·FCM + L |
| физ. защита | 2·vit·FCM + L |
| маг. защита | 2·men·FCM + L |
| точность | 0.5·dex·FCM + L |
| маг. точность | (0.4·men + 0.1·dex)·FCM + L |
| уклонение (avoid) | 0.5·agi·FCM + L |
| маг. уклонение | 0.5·men·FCM + L |
| шанс крита, % | 0.2·luk + 3 |
| сила крита | 80 (крит = урон × 1.8) |
| скорость атаки / каста | 100 (+ оружие, умения) |
| восстановление HP и MP | 5·FCM % + (2·L + 48) |
| шанс добычи | 0.2·luk |

**Попадание** (физ. и маг.): шанс, % = точность / уклонение цели × max(10, 2·(44 + L атакующего − L цели)) + 7
+ бонус умения; бросок 0…99. Равные уровни и равные точность/уклонение — 95 %; цель на 10 ур. выше — 75 %;
на 39+ выше — 17 %.

**Урон** (A — атака, D — защита цели (физ. или маг.; при блоке щитом D + блок), L — уровень атакующего):

    урон = A · max(0.05, 1 − 0.5·D/A) + 1.7·L · max(0.3, 1 − 0.4·D/A),  не меньше 1

затем разброс ±5 % от A, крит (шанс крита: бросок 0…99 < шанс; урон + урон·80/100), стихия: × (1 − сопротивление/300).
Защита вычитается наполовину, пока она меньше 1.9·A; при D ≥ 1.9·A проходит 5 % атаки + 30 % «уровневой» части.

## Умения, заточка, золото

- **Урон умений** (`StructSkill::PHYSICAL_SINGLE_DAMAGE`, тип 30001; `SINGLE_MAGICAL_DAMAGE`, тип 231): физический —
  атака × (var1 + var2 × SL) + var3 + var4 × SL; магический — маг. атака × (var1 + var2 × SL + var3 × заточка умения) +
  var4 + var5 × SL + var6 × заточка. Дальше — общая формула урона с защитой. У нас уровень умения n = SL 2n.
- **MP умений** — cost_mp + cost_mp_per_skl × SL; перезарядка — delay_cooltime (с), каст — delay_cast.
- **Заточка обычным кубом** (EnhanceResource, «Cube - Strike»): +1…+4 — 100 %, +5 70, +6 60, +7 50, +8 40, +9 35,
  +10 30, +11 25, +12 20, +13 15, +14 12, +15 10, +16 9, +17 8, +18 7, +19 6, +20 5 %.
- **Золото со зверя** — шанс 80 %, вилка по уровню (1 ур. 4–7, 10 ур. 22–37, 20 ур. 33–54, 30 ур. 46–76; у нас ×4).
